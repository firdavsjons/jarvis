# Быстрые команды для Jarvis

Jarvis запускает команды приложения «Быстрые команды» (Shortcuts) через `shortcuts run`, но только те, что вы сами
разрешили в файле `~/Library/Application Support/Jarvis/shortcuts_allowed.json`. Команды я не создаю: их делаете вы.

Зачем: приложение «Часы» не управляется скриптами, поэтому будильник и таймер **в самом приложении «Часы»**
возможны только через Быстрые команды. Фраза «поставь будильник в приложении Часы на 7 утра» запускает `Jarvis Alarm`.
Без этих команд Jarvis честно ответит «В приложении Часы это делается через Быстрые команды…» и предложит свой
внутренний будильник (он срабатывает, только пока Jarvis запущен).

## Что проверено, а что нет
- Проверено на этом Mac (macOS 26.4.1): утилита `shortcuts` есть; `shortcuts run` принимает `--input-path` и
  `--output-path`; у вас сейчас нет ни одной команды с именем `Jarvis …`.
- **Не удалось проверить**: есть ли в Быстрых командах действия «Создать будильник» / «Запустить таймер» /
  «Установить фокус» на вашей версии macOS. Каталог действий лежит внутри системных библиотек, и без запуска
  приложения его не прочитать. Проверьте сами (шаг 1). Если действия «Создать будильник» нет, команду
  `Jarvis Alarm` не создавайте и пользуйтесь внутренним будильником Jarvis. Остальное не пострадает.

## Шаг 0. Как посмотреть, какие действия есть
1. Откройте приложение «Быстрые команды» → «Файл» → «Новая быстрая команда».
2. В правой панели в поиске действий вводите по очереди: `будильник`, `alarm`, `таймер`, `timer`, `фокус`, `focus`.
3. Нужны действия: **Создать будильник** (Create Alarm), **Запустить таймер** (Start Timer),
   **Установить фокус** (Set Focus). Нашли — продолжайте с соответствующей командой; не нашли — пропустите её.

## Команда «Jarvis Alarm» (будильник в приложении Часы)
Вход: текст вида `07:30 Подъём` — время `ЧЧ:ММ` и необязательное название.
1. Новая быстрая команда → название **Jarvis Alarm** (регистр и пробел важны).
2. В настройках команды (кнопка «i» справа) включите «Принимать» и оставьте тип входа «Текст».
3. Действие **Разделить текст** (вход — «Ввод быстрой команды», разделитель «Пользовательский», символ — пробел),
   затем **Получить элемент из списка** → «Первый элемент»: это время.
4. Действие **Создать будильник** → время = первый элемент, подпись = «Быстрая команда Jarvis» (или оставьте пустой).
5. Проверка: в Терминале выполните
   `echo "07:30 Проверка" > /tmp/in.txt && shortcuts run "Jarvis Alarm" --input-path /tmp/in.txt`
   — в приложении «Часы» появится будильник; удалите его руками.

## Команда «Jarvis Timer» (таймер в приложении Часы)
Вход: число секунд, например `300`.
1. Новая быстрая команда → название **Jarvis Timer**, принимает «Текст».
2. Действие **Запустить таймер** → длительность = «Ввод быстрой команды», единица «секунды».
3. Проверка: `echo 60 > /tmp/in.txt && shortcuts run "Jarvis Timer" --input-path /tmp/in.txt` — запустится таймер
   на минуту (в приложении «Часы» его можно отменить).

## Команда «Jarvis Focus» (включить / выключить фокус «Не беспокоить»)
Вход: `on` или `off`.
1. Новая быстрая команда → название **Jarvis Focus**, принимает «Текст».
2. «Если» (Ввод = `on`) → **Установить фокус** «Не беспокоить», включить; «Иначе» → тот же фокус, выключить.
3. Проверка: `echo on > /tmp/in.txt && shortcuts run "Jarvis Focus" --input-path /tmp/in.txt`, затем `off`.
4. Первый запуск попросит разрешение на управление фокусом — разрешите.

## Список разрешённых: `shortcuts_allowed.json`
Файл создаётся автоматически при первом обращении (права 600, папка вне проекта). **Менять его можете только вы, руками.**
Ни один инструмент, ни ответ нейросети, ни быстрое правило Jarvis в этот файл не пишут (проверяет тест).

```json
{
  "Jarvis Alarm": "SAFE",
  "Jarvis Timer": "SAFE",
  "Jarvis Focus": "SAFE"
}
```

### Как добавить свою команду вручную
1. Откройте файл в редакторе: `open -e "$HOME/Library/Application Support/Jarvis/shortcuts_allowed.json"`.
2. Добавьте строку с **точным** именем команды из приложения (как в `shortcuts list`), например `"Выключить свет": "CONFIRM"`.
3. Сохраните. Перезапускать Jarvis не нужно: файл читается при каждом запуске команды.

### Какой уровень ставить
- `SAFE` — запускается сразу. Только для безобидных команд без побочных эффектов, которые нельзя использовать
  во вред (будильник, таймер, фокус).
- `CONFIRM` — Jarvis назовёт команду и спросит «да или нет». Ставьте на всё, что что-то отправляет, удаляет,
  включает или выключает в доме, меняет настройки, открывает сети и так далее. Имя без уровня (если вместо словаря
  в файле просто список имён) тоже считается `CONFIRM`.
- Имени нет в файле — запуск запрещён (`BLOCKED`), даже если команда есть в приложении.

Результат команды (до 300 символов) считается чужими данными: после него в той же фразе Jarvis не будет удалять,
отправлять, закрывать приложения, запускать другие команды и менять память — на случай, если результат содержит
вредные указания.

## Если что-то не работает
- «Команды … нет в приложении» — имя в файле не совпадает с именем в приложении (регистр, пробелы).
- «Нужно разрешение … Быстрые команды» — Системные настройки → Конфиденциальность и безопасность →
  Автоматизация → разрешите приложению, из которого запущен Jarvis (Терминал, VS Code…), управлять «Быстрыми командами».
- Команда выполняется дольше 30 секунд — Jarvis её прервёт.
