# Распознавание речи: локальный Whisper (Этап 8.1)

Jarvis распознаёт речь локально: звук остаётся на вашем Mac. Google (`recognize_google`) — запасной вариант, который
включается одной строкой в `.env`.

## Как это устроено

```
микрофон (speech_recognition: пауза SPEECH_PAUSE, фраза до SPEECH_PHRASE_LIMIT секунд)
   │  запись < 0,4 с — отбрасывается
   ▼
движок из STT_ENGINE ── whisper_cpp (основной) / faster_whisper (запасной) / google
   │  локальный Whisper получает подсказку (имена, приложения), Google — никогда
   ▼
фильтр шума и галлюцинаций → текст → «обрезанная фраза?» → Jarvis
```

- **Код** — пакет `core/stt/`: `base.py` (типы), `whisper_local.py` (загрузка, прогрев, выгрузка, фильтр),
  `whisper_cpp.py` и `faster.py` (два движка), `google.py`, `service.py` (откат, оповещения, журнал времени),
  `factory.py` (настройки `.env`), `prompt.py` (подсказка), `blacklist.py`, `truncated.py`, `check.py` (проверка вручную).
- Пока пакет и модель не установлены, Jarvis работает на Google и один раз за запуск говорит:
  «Локальное распознавание не установлено, использую Google.»

## Приватность: куда уходит звук

| Настройка | Куда идёт звук |
|---|---|
| `STT_ENGINE=whisper_cpp` (или `faster_whisper`), `STT_FALLBACK=off` | **Никуда, остаётся на Mac** |
| `STT_ENGINE=whisper_cpp`, `STT_FALLBACK=google` (по умолчанию) | Локально. В Google — **одна фраза за раз**, только если локальный движок сломался (нет пакета или модели, ошибка, модель ещё грузится при запуске) |
| `STT_ENGINE=google` | **Каждая фраза уходит в Google** (как до Этапа 8.1) |

- Откат на Google — только по технической причине. Шум, тишина и отброшенные галлюцинации в Google **не** отправляются.
- Подсказка Whisper (имена контактов, приложения) в Google не передаётся никогда.
- Распознанный текст остаётся таким же личным, как раньше: он идёт в облачную модель (Gemini, Groq) как обычная команда.
  Локальное распознавание защищает только сам **звук**.
- Хотите, чтобы звук не уходил из Mac совсем: `STT_FALLBACK=off`. Если локальный движок не работает, Jarvis
  один раз скажет «Локальное распознавание не установлено, откат на Google выключен.», дальше — «Не удалось распознать
  речь» (не чаще раза в 20 секунд).

## Установка (вручную; Jarvis сам ничего не скачивает и не устанавливает)

Проверено по метаданным PyPI и Hugging Face для Python 3.14 на Apple Silicon; **на вашем Mac живьём ещё не запускалось**.

> В .venv скрипты (pip и др.) указывают на старый путь после переноса проекта; запускайте только `python -m pip`. Пересоздание окружения — Этап 13.

1. **Пакет** (основной движок whisper.cpp): готовое колесо без сборки и без torch, Metal внутри; вместе с зависимостями
   (numpy, requests, tqdm, platformdirs) ≈ 17 МБ.
   ```bash
   .venv/bin/python -m pip install pywhispercpp==1.5.1
   ```
2. **Модель** — файл ggml в папку моделей Jarvis. Выбор:

   | Модель (`STT_MODEL`) | Файл | На диске | Память при работе* | Скорость на M1* | Русский* |
   |---|---|---|---|---|---|
   | `large-v3-turbo-q5_0` (по умолчанию) | `ggml-large-v3-turbo-q5_0.bin` | 574 МБ | ≈ 0,7–1,5 ГБ | фраза 3–5 с за ≈ 0,5–1,5 с | лучшее; ошибок на слово ≈ 6–9% |
   | `small-q5_1` (лёгкая) | `ggml-small-q5_1.bin` | 190 МБ | ≈ 0,4–0,8 ГБ | заметно быстрее | слабее: ≈ 15–20%, хуже на коротких командах и именах |

   \* Это **оценки по открытым замерам whisper.cpp**, на вашем Mac они не измерялись. Реальное время смотрите в логе (ниже).

   ```bash
   mkdir -p ~/Library/Application\ Support/Jarvis/models
   cd ~/Library/Application\ Support/Jarvis/models
   curl -L -O https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
   shasum -a 256 ggml-large-v3-turbo-q5_0.bin
   # 394221709cd5ad1f40c46e6031ca61bce88931e6e088c188294c6d5a55ffa7e2

   # лёгкая модель: ggml-small-q5_1.bin, sha256 ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb
   ```
   Размеры файлов: 574 041 195 и 190 085 487 байт. Для `small-q5_1` впишите в `.env` `STT_MODEL=small-q5_1`.
   Jarvis никогда не скачивает модель сам: pywhispercpp скачал бы ненайденную модель без проверки суммы, поэтому ему
   всегда отдаётся путь к существующему файлу.
3. **Проверка** (микрофон не включается, звук никуда не уходит):
   ```bash
   .venv/bin/python -m core.stt.check                 # настройки, пакет, файл модели, загрузка и прогрев
   .venv/bin/python -m core.stt.check --wav фраза.wav # распознать файл: текст, время, уверенность
   .venv/bin/python -m core.stt.check --mic           # записать одну фразу с микрофона и распознать
   ```
   Первая загрузка и прогрев на вашем M1 заняли 18,0 с (Metal готовит шейдеры; Metal задействован). По вашей живой проверке: модель загружается за ~10 с, распознавание ~2 с на фразу независимо от её длины. Реальное время каждой загрузки покажет эта команда и лог.

### Запасной движок: faster-whisper

Работает на процессоре (Metal нет), поэтому большие модели медленнее; зато умеет `no_speech_prob`. Вместе с зависимостями
≈ 63 МБ.
```bash
.venv/bin/python -m pip install faster-whisper==1.2.1
.venv/bin/python -c "import os, huggingface_hub as h; h.snapshot_download('Systran/faster-whisper-small', \
local_dir=os.path.expanduser('~/Library/Application Support/Jarvis/models/faster-whisper/small'))"   # ≈ 484 МБ
```
В `.env`: `STT_ENGINE=faster_whisper` (модель по умолчанию `small`, свой вариант — `STT_MODEL=<имя папки>`).
Если сменили движок, а `STT_MODEL` остался от другого, модель «не найдена» — Jarvis скажет, что распознавание не
установлено, и сработает откат.

## Настройки `.env`

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `STT_ENGINE` | `whisper_cpp` | `whisper_cpp`, `faster_whisper` или `google`. Неизвестное значение — `whisper_cpp` и предупреждение в лог (не Google: звук не должен уйти в интернет из-за опечатки) |
| `STT_FALLBACK` | `google` | `google` или `off` (также `no`, `false`, `0`, `none`) |
| `STT_MODEL` | пусто | Пусто — модель по умолчанию движка |
| `STT_LANGUAGE` | `ru` | Язык распознавания; для Google превращается в `ru-RU` |
| `STT_THREADS` | `4` | Потоков процессора. **Не больше половины ядер** (на 8 ядрах — 4): выше ограничивается |
| `STT_PROMPT` | `on` | `on` или `off`: подсказка Whisper (см. ниже); `off` — не передаётся вообще |
| `STT_UNLOAD_MINUTES` | `10` | Простой, после которого модель выгружается из памяти. `0` — не выгружать |
| `SPEECH_PHRASE_LIMIT` | `20` | Самая длинная фраза, секунд (3–60). Раньше было 5 |
| `SPEECH_PAUSE` | `1.2` | Пауза, после которой фраза считается законченной (не менялась) |

После изменения `.env` перезапустите Jarvis.

## Как вернуться на Google, отключить откат, сменить модель

- **Вернуться на Google** (как до Этапа 8.1): в `.env` одна строка `STT_ENGINE=google`. Модель не загружается совсем,
  подсказка не строится, откат не нужен.
- **Отключить откат на Google** (звук не уходит из Mac): `STT_FALLBACK=off`.
- **Сменить модель**: положите файл в `~/Library/Application Support/Jarvis/models/` (для whisper.cpp — `ggml-<имя>.bin`)
  и впишите `STT_MODEL=<имя>`, например `small-q5_1`.
- **Посмотреть время распознавания**: в логе `~/Library/Logs/Jarvis/jarvis.log` на каждую фразу строка
  «Распознавание (whisper_cpp): запись 3.2 с, обработка 0.8 с» — текст в неё не попадает. Быстрый просмотр:
  ```bash
  grep "Распознавание (" ~/Library/Logs/Jarvis/jarvis.log | tail -20
  ```
  Дольше 8 секунд — предупреждение «Распознавание заняло … с (больше 8 с)»: возьмите модель полегче (`small-q5_1`).
  При запуске в лог пишутся «Модель распознавания … загружена за … с» и «Прогрев модели …»; строка
  «Распознавание речи: …» сообщает, куда идёт звук.

## Загрузка и выгрузка модели

- При запуске модель грузится **в фоновом потоке**, окно открывается сразу; сразу после загрузки идёт прогрев на
  полсекунды тишины (первое обращение к Metal медленное).
- Пока модель не готова: при `STT_FALLBACK=google` фразы распознаёт Google, при `off` Jarvis говорит «Распознавание
  загружается, секунду.» (не чаще раза в 20 секунд).
- После `STT_UNLOAD_MINUTES` минут без команд модель выгружается из памяти. Следующая фраза загрузит её заново
  (несколько секунд ожидания), звук при этом остаётся на Mac. Во время распознавания модель не выгружается.
- Если модель не загрузилась (битый файл, нет памяти), это считается сбоем: Jarvis один раз скажет «Локальное
  распознавание не запустилось, …» и до перезапуска не будет пробовать снова.

## Фильтр шума и галлюцинаций

На тишине и шуме Whisper иногда «дописывает» фразы из субтитров. Каждый кусок речи отбрасывается, если:

| Критерий | Порог | whisper_cpp | faster_whisper |
|---|---|---|---|
| вероятность отсутствия речи `no_speech_prob` | > 0,6 | делает сам whisper.cpp (`no_speech_thold`, вместе с `logprob_thold`) | наш фильтр |
| средний логарифм вероятности `avg_logprob` | < −1,0 | наш фильтр: ln(средняя вероятность токенов), поле `probability` | наш фильтр |
| текст из чёрного списка (`core/stt/blacklist.py`) | совпадение или начало фразы | наш фильтр | наш фильтр |
| длина записи | < 0,4 с | для любого движка | для любого движка |

Чёрный список: «продолжение следует», «субтитры сделал…», «субтитры создавал…», «спасибо за просмотр»,
«подписывайтесь на канал», «редактор субтитров…» (+ «субтитры делал…», «благодарю за просмотр»). Сравниваются
нормализованные строки (регистр, «ё», знаки препинания не важны), совпадение — вся фраза или её начало.
В лог идёт «Отброшено (шум/галлюцинация)» без текста. Откат на Google после этого **не** выполняется.

**Ограничение whisper_cpp:** Python-обёртка pywhispercpp не отдаёт `no_speech_prob` наружу, поэтому этот критерий
выполняет внутри себя whisper.cpp (отсекает кусок, когда `no_speech_prob` > 0,6 **и** `avg_logprob` < −1,0), а не наш код.
Если на тишине всё же появляется чужой текст — пришлите его (в лог текст не пишется, нужна проверка через
`python -m core.stt.check --wav`), будет добавлен в чёрный список, либо переключитесь на `faster_whisper`.

## Подсказка Whisper (`initial_prompt`) и эхо подсказки

Whisper продолжает подсказку как предыдущий текст. Прежняя подсказка с метками («Контакты: мама, босс») протекала в
результат: «Контакты: Да.», «Контакты: закрой, как вы видите?», и «закрой калькулятор» закрыло приложение «Контакты».
Поэтому (Этап 8.1.2) подсказка теперь — несколько **обычных командных предложений** без меток, двоеточий и списков:

```
Джарвис, открой калькулятор. Закрой сафари. Напиши маме в телеграм привет. Поставь таймер на пять минут.
Какая погода в Душанбе? Открой телеграм.
```

- Шаблоны в порядке приоритета: «Джарвис, открой {приложение}.», «Закрой {приложение}.», «Напиши {контакт} в телеграм
  привет.», «Поставь таймер на пять минут.», «Какая погода в {город}?», затем «Открой {приложение}.» и второй контакт,
  если влезают. Размер — **не больше 80 токенов** (1 токен ≈ 2 символа).
- Не больше **3 приложений** (русские названия установленных: ключи `APP_ALIASES` и добавки ватсап, ютуб, вайбер… — в
  винительном падеже) и **2 контактов** (только ключи `contacts.json`, без username и телефонов; в дательном падеже:
  мама → маме, Иван → Ивану, «себе» без изменений). Ключ с «@» или цепочкой из 5+ цифр пропускается.
- Город — `DEFAULT_CITY` из `.env` (по умолчанию Душанбе), в предложном падеже; название из нескольких слов или латиницей
  не склоняется, тогда «Какая сегодня погода?».
- Набор приложений и контактов **сдвигается по кругу** при каждом построении, раз в 10 минут.
- Английских названий и псевдонимов из памяти в подсказке нет (они провоцируют эхо).
- В Google подсказка не уходит. В лог пишется только длина.

### `STT_PROMPT=on|off`
`on` (по умолчанию) — подсказка передаётся Whisper. `off` — подсказка не строится и не передаётся вообще. Метки подсказки
из текста при этом всё равно убираются.

### Защита от эха подсказки (`core/stt/prompt_echo.py`)
Если Whisper всё же дописал или повторил подсказку:
1. **Метки.** «контакты:», «приложения:», «команды:», «программы:», «как я называю приложения:» (с двоеточием, регистр не
   важен) удаляются из любого места текста: «Контакты: Да.» → «Да.», «Контакты: Светилик.» → «Светилик.». Слово без
   двоеточия («закрой контакты») меткой не считается. Остался пустой текст — фраза отбрасывается.
2. **Предложение подсказки.** Текст целиком совпал с предложением подсказки — это эхо, **только если** запись слишком
   коротка для такого текста (больше 20 символов текста на секунду записи) **или** уверенность Whisper ниже 0,5. Иначе
   это настоящая команда: «поставь таймер на пять минут» и «закрой сафари» совпадают с предложениями подсказки, но
   сказанные вслух не отбрасываются. Пороги оценочные, подобрать по логу (`ECHO_MAX_CHARS_PER_SECOND`,
   `ECHO_MAX_CONFIDENCE` в `prompt_echo.py`).
3. **Лог (без текста), счётчики за запуск:** «Убраны метки подсказки, всего: N» и «Отброшено (эхо подсказки), всего за
   запуск: N». Эхо в Google не отправляется.
4. **Предупреждение.** Если подсказка включена и три фразы подряд с метками или эхом, в лог: «Подсказка искажает
   распознавание; сравните: python -m core.stt.check --mic --no-prompt, или STT_PROMPT=off».

### Как сравнить качество с подсказкой и без
```bash
.venv/bin/python -m core.stt.check --mic                 # 3 фразы с подсказкой (печатается сама подсказка)
.venv/bin/python -m core.stt.check --mic --no-prompt     # те же фразы без подсказки
.venv/bin/python -m core.stt.check --mic --repeat 5      # свой счёт фраз
```
Для каждой фразы выводятся текст, длина записи, время распознавания и уверенность. Скажите одни и те же фразы
(«открой калькулятор», «закрой сафари», «напиши маме привет») оба раза и сравните. Лучше — оставьте то, где меньше
ошибок; хуже с подсказкой — `STT_PROMPT=off`.

## Слово-активатор

Whisper распознаёт всю речь рядом, и без проверки Jarvis пытался выполнять любую фразу («Нет, но…», «Спасибо.» — ответил
«Пожалуйста», «Сибирь.» — искал контакт). Теперь голосовая фраза обрабатывается, только если она **обращена к Jarvis**
(Этап 8.2). Слово ищется в уже распознанном тексте.

### Как это работает
- **Слова:** «джарвис», «jarvis», «жарвис», «джарвес», «дарвис», «чарвис», «ярвис» (регистр, «ё» и знаки не важны).
- **Где слово считается:**
  - в начале: слово 1 либо слово 2 после одного междометия («эй», «ну», «окей», «ок», «слушай», «привет»); допускается
    одна ошибка (difflib ≥ 0,8): «джарвиз», «жарвис» подойдут;
  - в самом конце: «открой калькулятор, Джарвис» (только точное слово);
  - в середине фразы **не считается**.
- **Слово есть:** оно и междометие вырезаются, остаток обрабатывается как обычная команда: «Джарвис, открой
  калькулятор» → «открой калькулятор». Сказали только «Джарвис» — ответ «Слушаю.» (без запроса к модели).
- **Слова нет и окна нет:** фраза молча отбрасывается: ни ответа, ни модели, ни кэша, ни быстрых правил, ни истории, ни
  журнала действий. В лог — «Отброшено (нет слова «Джарвис»)» без текста и каждые 10 отброшенных «за запуск отброшено N
  фраз без обращения». Текст отброшенной фразы не записывается нигде (в лог он теперь попадает только после проверки).
- **Окно диалога:** слово не нужно `WAKE_WINDOW` секунд (по умолчанию 8) после каждого озвученного ответа Jarvis на
  команду или вопрос, считая от конца озвучки до **начала** вашей фразы. Если Jarvis задал вопрос («Кому именно?»,
  «Какой текст?»), окно держится 20 секунд. Окно **не открывают** «Секунду.», таймер, будильник и оповещения
  распознавания («Локальное распознавание не установлено…»); «Слушаю.» открывает его.
- **Слова не требуют:** ответ на ожидающее подтверждение («да», «нет», любой ответ), «стоп», «хватит», «отмена» и
  текстовое поле. «Стоп» и «хватит» останавливают озвучку, закрывают окно и молчат; пока ждёт подтверждения — это отмена.
  Окно закрывается также по «стоп», «хватит» и «отмена».
- **Порядок проверок** в `process_command`: подтверждение → стоп/отмена → слово/окно → обрывки и обрезанные фразы →
  остальное. Отброшенная фраза не тратит ничего: ни проверки на обрезанность, ни модели.

### Слово из подсказки
Подсказка Whisper начинается с «Джарвис» («Джарвис, открой калькулятор. …»), и Whisper может дописать это слово к
посторонней речи. Поэтому, если распознанный текст **начинается** со слова, а запись короче 1,2 с или уверенность Whisper
ниже 0,5, слово помечается «возможно из подсказки» и засчитывается только если после него есть команда из 2+ слов **и**
уверенность не ниже 0,5. Примеры: «Джарвис.» на записи 0,6 с с уверенностью 0,4 — не обращение, окно не открывается;
«Джарвис, открой калькулятор» на записи 3 с с уверенностью 0,9 — обращение. Пороги (1,2 с, 0,5, 2 слова) оценочные,
подобрать по логу (`core/wake.py`). Как смотреть: `python -m core.stt.check --mic --wake` — для каждой записи
показывает, засчитано ли слово и почему (окно диалога в этой проверке не моделируется).

### Настройки и выключение
```
WAKE_WORD=on      # по умолчанию; off — слово не нужно, Jarvis отвечает на любую услышанную фразу (как раньше)
WAKE_WINDOW=8     # секунд (3–30) без слова после каждого ответа Jarvis; после вопроса всегда 20
```
Текстовое поле слова не требует никогда. После изменения `.env` перезапустите Jarvis.

### Честные ограничения
- Whisper по-прежнему распознаёт **каждую** фразу вокруг (нагрузка на процессор, ~2 с на фразу): слово ищется в готовом
  тексте. Настоящий детектор слова без Whisper (openWakeWord, Porcupine) — отдельный шаг, **не сделан**.
- Нечёткий поиск принимает близкие слова: «Дарвин» в начале фразы сработает как обращение (0,83).
- Голосовое прерывание речи («стоп» во время озвучки) не сделано: пока Jarvis говорит, микрофон не слушает. «Стоп» работает
  в паузах и при ожидании подтверждения.
- Если слово не засчитано (шумная запись, неуверенное распознавание), скажите фразу ещё раз; в логе будет «Слово
  «Джарвис» не засчитано: …».

## Повторы Whisper

Whisper иногда зацикливается: «Открой калькулятор. Открой калькулятор.». Схлопываются только повторы **предложений**
(весь текст — одно предложение из 2+ слов, повторённое 2+ раза) и **фраз из 2+ слов** (одна и та же фраза 3+ раза подряд
в любом месте). Повторы одного слова («громче громче громче», «стоп стоп») не трогаются — их говорят нарочно. Сравнение
по нормализованным словам; Google-текст не меняется. В лог идут только длины.

## Обрезанные фразы (любой движок)

Распознавание иногда теряет конец фразы. Фраза из двух слов и больше считается обрезанной, если последнее слово —
предлог, союз или частица (в, на, с, к, и, о, у, не, по, до, за, из, от, но, а …) либо короче трёх букв. Тогда
Jarvis говорит «Фраза обрезана. Повторите, пожалуйста.» и **не передаёт её модели**. Не считаются обрезанными: слова
подтверждения и управления (да, нет, стоп, хватит, отмена, подтверждаю), я, ты, мы, вы, он, ок, ну, тв, вк, любые числа,
а также ответ на ожидающее подтверждение и текст, набранный в окне.

Примеры: «позвонить ма», «напиши себе в», «открой чат с» — обрезаны; «кто я», «включи тв», «поставь на 5»,
«открой ватсап» — нормальные.

## Неполадки

| Симптом | Что делать |
|---|---|
| «Локальное распознавание не установлено…» | `python -m core.stt.check`: покажет, чего нет — пакета или файла модели |
| «Локальное распознавание не запустилось…» | Файл модели повреждён (проверьте `shasum -a 256`) или не хватило памяти: возьмите `small-q5_1` |
| Распознавание дольше 8 с | Лёгкая модель, `STT_THREADS=4`, закройте тяжёлые программы |
| Всё уходит в Google | Смотрите строку «Распознавание речи: …» в начале лога и предупреждения «не сработало» |
| Ноутбук греется | Уменьшите `STT_THREADS`, увеличьте простой выгрузки или возьмите `small-q5_1` |
