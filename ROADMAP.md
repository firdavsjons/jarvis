# Jarvis для Mac — полный TO-DO (от текущего состояния до готового ассистента)

## Принятые решения
- Язык: только русский (английский — позже).
- Telegram: через приложение Telegram Desktop на Mac.
- «Мозг»: облачная модель по API (умнее и не нужно запускать LM Studio) + поиск в интернете. Локальные Qwen 7B / Gemma 4B — позже как офлайн-режим.
- Mac: 16 ГБ памяти → локальный Whisper работает без проблем.
- Безопасность: три уровня риска (сразу / с подтверждением / запрещено).

## Как выглядит готовый проект
Иконка Jarvis в строке меню. Вы говорите «Джарвис, открой Telegram и напиши Ане, что я задерживаюсь» → он повторяет текст голосом, ждёт «да» и отправляет. «Джарвис, какая сегодня погода / что нового про X» → ищет в интернете и коротко отвечает вслух. «Удали системную папку» → отказ.

## Сценарии приёмки (проект готов, когда всё это работает)
1. «Джарвис, открой калькулятор» → открывается сразу.
2. «Джарвис, сделай потише» → громкость меняется.
3. «Джарвис, какая погода в Душанбе» → ответ голосом.
4. «Джарвис, напиши Ане в Telegram, что я опоздаю» → зачитывает текст, ждёт «да», отправляет.
5. «Джарвис, закрой Safari» → просит подтверждение.
6. «Джарвис, удали папку System» → отказ, запись в журнале.
7. «Джарвис, удали файл отчёт с рабочего стола» → подтверждение, файл уходит в Корзину.
8. Нет интернета → вслух говорит об этом, локальные команды работают.
9. Фоновый разговор рядом не запускает команды (нужно слово «Джарвис»).
